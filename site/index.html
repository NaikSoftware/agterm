Terminal workspace · macOS, Linux, Android

Park every agent. Watch them all.

Hangar is a native terminal built to run many coding agents at once. Every agent works in its own named session, sessions sit in workspaces, and the sidebar shows which one is working, which one waits for you, and which one is done.

Bay 01StatusSidebar

See every agent at once.

A tabbed terminal loses track of five agents in five projects. Hangar keeps them in one tree. Each workspace holds the sessions of one project and remembers its folder, and each agent reports its state onto its own row.

WorkingA blue circle fades in and out, and a slow wave runs across the row.
Needs youA triangle: a permission prompt or a question.
DoneA diamond marks a finished turn until you look at it.

Bay 02Switcher⌃P

Jump to the one that needs you.

Click the session title in the title bar or press ⌃P. Search every session, see the blocked ones first, and reopen a session you closed by mistake.

Bay 04PhoneAndroid

Answer an agent from your pocket.

Hangar for Android shows the same workspace tree as the desktop. An agent's question arrives as answer buttons, so a permission prompt is one tap.

Wi‑Fi USB Bluetooth
New sessionStart a terminal or an agent in any workspace and folder.
Fit to phoneThe program redraws for the phone's columns and rows. The desktop gets its size back when the phone disconnects.
AlertsA notification when an agent blocks or finishes. It goes away when you read the session on the computer.

The relay is off by default and uses TLS pinned to your computer's certificate. Anyone with the pairing code controls your terminals until you revoke it.

Bay 05Control APIhangarctl
zsh
ws=$(hangarctl workspace new demo)
sid=$(hangarctl session new --workspace "$ws" --no-select)
# start an agent in a session you are not looking at
hangarctl session type $'claude\n' --target "$sid"
# read its screen back, then mark it in the sidebar
hangarctl session text --target "$sid" --lines 10
hangarctl session status blocked --target "$sid"
# ask the human; the answer comes back on stdout
hangarctl ask "Deploy now?" --button yes=Deploy --button no=Later
hangarctl tree --json # the whole model as JSON

Your agents drive the terminal.

The bundled hangarctl drives everything over a local socket, one command per call. An agent skill teaches your agent to use it, so the agent builds its own layout, shows you a page, or asks you a question.

You rarely write these by hand. Ask the agent in your session for a key binding, a layout or a workflow, and the skill writes it.

Get the APK

Up in a minute.

On macOS, the first launch installs hangarctl, the agent status hooks and the agent skill. Each update refreshes them.

1

Download the DMG from the latest release, open it, and drag Hangar to Applications.

2

Clear the download flag once. The build is not notarized.

xattr -dr com.apple.quarantine /Applications/Hangar.app
3

Start Hangar and run an agent in the first session. To pair the phone, open the app menu ▸ Connect a Phone… and scan the code.
