Terminal workspace for AI coding agents

Herd your agents. Miss none of them.

Elis is a native terminal for macOS and Linux. It runs many coding agents at once. Each agent works in its own named session. Sessions sit in tinted workspaces. The sidebar shows which agent is working, which agent needs you, and which agent is done.

Features

Many sessions, one window.

Session switcher ⌃P

Search all sessions. Sessions that need you come first.

Live sessions

Agents keep running when you quit or update Elis. The next launch reattaches them.

Splits, companions, overlays

Split a session, pin a log under it, or run a program over its shell.

Remote sessions

Attach sessions from another Mac over ssh, with their status.

Drag and drop

Agents coordinate with each other.

Drag sessions and files into an agent's prompt. A file from the file panel adds its path. A session adds its id, and the agent can talk to that session.

Control API

Agents control the terminal.

With elisctl and the agent skill, an agent opens sessions, reads their screens and asks you questions. Command reference →

zsh
sid=$(elisctl session new --no-select)
elisctl session type $'claude\n' --target "$sid"
elisctl session text --target "$sid" --lines 10
elisctl ask "Deploy now?" --button yes=Deploy --button no=Later
Install

macOS and Linux.

macOS

Apple Silicon, macOS 14 or later

  1. Download the DMG from the latest release. Drag Elis to Applications.
  2. Clear the quarantine flag once. The build is not notarized.xattr -dr com.apple.quarantine /Applications/Elis.app
  3. Start Elis. The first launch installs elisctl, the agent status hooks and the agent skill.
